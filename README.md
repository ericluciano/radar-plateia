# Radar da Plateia

Filma a plateia pela webcam e **apita no PC** quando alguem fica de cabeca baixa
(celular/teclado) por 6s+ ou some da camera. 100% local: nao grava, nao identifica, nao envia nada.

**Usar:** dois cliques em `RADAR.bat` (tem copia na area de trabalho). Janela abre com a camera;
caixa verde = atento, vermelha = disperso, laranja = sumiu da camera.

**Teclas:** `m` mudo | `+`/`-` tolerancia de cabeca baixa | `1-9` apita a partir de N dispersos | `p` pausa | `q` sair.

Apitos ficam registrados em `logs/eventos.log`. Detalhes tecnicos: `CLAUDE.md`.
